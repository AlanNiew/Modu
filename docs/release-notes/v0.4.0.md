# 墨读 v0.4.0

本次是「按使用反馈重做界面与设置」的大版本：顶栏改成固定菜单栏、设置拆成独立页面并把选项全部开放，另外补上自定义字体、繁体转简体、系统托盘与开机自启。书架、进度、书签、批注数据全部兼容，升级不需要任何迁移操作。

## 新界面

- **固定菜单栏**：书架页和阅读页共用同一条顶栏，菜单分组为「文件 / 阅读 / 视图 / 帮助」，切换页面菜单不会跳动；窗口按钮固定在右侧。
- **侧栏开关独立**：目录/书签/搜索开关移到菜单栏左侧，是一个随时可点、不带选中态的普通按钮。
- **全屏与沉浸分开**：全屏（F11）只隐藏窗口边框，沉浸模式隐藏整个顶栏与状态栏，两个图标也做了区分。

## 设置页

- 五个分组：外观、排版、转换、行为、关于。
- 排版选项全部开放：阅读流向、字号、行高、**页边距（重新独立可调，默认 24px）**、版心宽度、段间距、字间距、首行缩进、净版。
- 「启动时自动检查更新」从更新窗口迁到这里，与启动时的静默检查共用同一份状态。

## 字体

- 预设字体扩到 9 项：宋体、黑体、楷体、仿宋、等线、幼圆、霞鹜文楷、等宽、系统默认，每项都标注了字体类型。
- **支持导入自己的字体**：ttf / otf / ttc / woff / woff2 都可以，导入后可在设置里选择、随时删除；删除正在使用的字体会自动回退到默认宋体。

## 繁体转简体

- 设置-转换里新增「繁体自动转简体」开关，默认关闭。
- 转换在渲染前统一完成，正文、目录、搜索结果口径一致（搜简体词也能命中繁体原文）；书库文件保持原样，关闭开关即恢复繁体。

## 系统托盘与开机自启

- 托盘图标：左键显示/还原主窗口，右键菜单可打开设置、检查更新、切换开机自启、退出。
- **关闭窗口会询问一次**：主按钮是「最小化到托盘」，也可以选择「退出程序」，勾选「不再询问」后记住选择；之后可在设置-行为或托盘菜单修改。
- 支持开机自启（安装版）。卸载时会同时清理自启注册项。

## 修复

- **自动更新检查失败的问题**：此前发布包缺少 `latest.json` 清单，导致检查更新一律报 `Could not fetch a valid release JSON`。现在发布流程会强制上传并校验清单，检查失败的提示也改成了可执行的中文说明（附手动下载入口）。
- 数据目录继续使用 `%APPDATA%\Modu`，卸载程序不会删除书库。

## 升级说明

- 安装版直接在应用内「帮助 → 检查更新」即可升级，书架与阅读进度都会保留。
- 便携版请下载新的便携 ZIP 覆盖，数据目录不随程序目录变化。

**完整校验和与更新清单见 Release 附件（`latest.json`）。**

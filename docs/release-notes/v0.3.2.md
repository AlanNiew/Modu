# v0.3.2 · 数据更安全、安装更省心

## 这一版做了什么

- **卸载程序不再可能删掉你的书库**：数据目录从 `%APPDATA%\com.alanview.epubreader` 迁移到独立目录 `%APPDATA%\Modu`。
  此前安装器卸载向导里的「删除应用数据」勾选项会连带删除书架、进度、书签、批注；现在卸载只删程序。
  老版本数据会在首次启动时自动迁移（同盘改名，瞬间完成；失败则继续用旧目录，不丢数据）。
- **安装失败的自救指南**：README 与用户手册补充——若安装报「无法打开要写入的文件 …\modu.exe」，
  把「安装位置」从 `%LOCALAPPDATA%` 改到 D 盘可写目录（如 `D:\Apps\墨读`）再装即可；
  这类失败通常是安全软件拦截安装器往 AppData 写 exe，不是账户没权限。
- 文档同步：用户手册「11. 数据、备份与迁移」「13. 常见问题」、README「下载与安装」均已更新。

## 升级说明

- 安装版可直接覆盖安装（或等应用内自动更新）。
- 数据自动迁移，无需手动搬目录；排版设置随 WebView 数据目录保留。
- 安装位置建议放在自己可写的目录（如 `D:\Apps\墨读`），这样后续静默更新不需要 UAC。

## 校验

见发布页附件旁的 SHA-256；可用 `certutil -hashfile <文件名> SHA256` 对照。

# v0.3.1 · 自动更新

本次更新加入了应用内自动更新：以后发布新版本时，你会在启动后收到提示，点一下即可下载、校验、静默安装并重启，不再需要手动下载安装包。

## 新增

- **应用内检查更新**：启动时静默检查（可在更新面板里关闭），书架标题栏也有「检查更新」按钮。
- **更新说明与进度**：更新面板会显示新版本号、更新内容、下载进度；下载完成后自动安装并提示重启。
- **签名校验**：更新包使用 Ed25519 签名，客户端用内置公钥验签，校验失败即中止，不会执行安装包。
- **失败兜底**：网络异常或校验失败会给出手动下载入口，用户数据（书架、进度、书签、批注）不受影响。

## 说明

- 自动更新只在**安装版**中生效；便携版（ZIP）仍需手动替换 `Modu.exe`。
- 若安装在受保护目录（例如由管理员权限装到 `D:\Windows Tools`），静默安装仍可能弹一次 UAC。改用普通权限安装到 `%LOCALAPPDATA%` 可避免。
- 本版数据库结构未变，从 0.3.0 升级无需迁移操作。

# 墨读（Modu）v0.3.0 —— 审查加固：阅读定位回到原句

对 M0–M2 做了一轮「规范 + 结构」两轴审查后的加固版本。审查共暴露 19 项问题，本版全部处理；另外补齐了排版自由度、批注导出与静态检查门禁。

## 亮点

- **阅读定位升级（Locator v2）**：位置不再只记「章号 + 页分数」，而是记「章号 + 页分数 + 引文 + 前后各 32 字」。改字号、改版心、换窗口、退出重开，都会回到**原来那一句**，而不是那一页。旧数据自动升级，无需重新导入。
- **健壮性**：识别带 DRM 加密的正文并给出中文提示；压缩包单条目 64 MB 上限（防 zip 炸弹）；非 EPUB 文件明确说明缺什么，并提示「是不是把 zip 改了后缀」；书名缺失回退文件名。
- **排版更自由**：新增「段后间距 / 字间距 / 对齐方式 / 净版（忽略书内排版）」，排版面板共 10 项；拖滑杆重排加了 100ms 防抖，调整后位置不跳。
- **批注可导出**：批注面板右上「导出」→ 系统保存对话框 → 生成 Markdown（按章分组，引文 + 备注 + 颜色/时间），方便整理读书笔记。
- **安全**：章节 HTML 清洗增强 —— 移除 `form`/`iframe`/`meta refresh`、全部 `on*` 事件属性，拦截 `javascript:` / `vbscript:` 链接，`data:` 只放行图片。

## 修复

- 进度/书签只记页分数，换字号后位置漂移（→ Locator v2）
- 搜索关键词里的 `%`、`_` 未转义，会命中所有书（→ `LIKE ... ESCAPE`）
- `html_to_text` 不识别块级标签，`<p>甲</p><p>乙</p>` 被拼成「甲乙」，影响索引与摘录
- 目录高亮只看章，同一章的多个小节会一起点亮（→ 按 fragment 精确匹配）
- 非 EPUB / DRM 书报错信息晦涩
- 结构与清理：批注颜色改为类型安全的枚举；删除 3 个无调用者的命令；统一协议层的 CORS/缓存与错误响应

## 质量门禁

| 项目 | 结果 |
|---|---|
| Rust 单测（含 DRM、畸形样本、200 章大书基准） | **17 项全绿** |
| 前端单测（Locator / 清洗 / 设置 / 适配层） | **23 项全绿** |
| `cargo clippy --lib --tests -- -D warnings` | **零告警** |
| `pnpm lint`（新增 eslint 配置） | **零告警** |
| `pnpm typecheck` | **0 错误** |

实测（本机 debug 构建，200 章 / 26 万字）：打开 16 ms、全文读取 25 ms、导入 + 建全文索引 72 ms、一次搜索 <1 ms。

## 安装

本版提供两种下载形式，任选其一：

### A. 安装版（推荐给日常使用）

- 文件：`墨读_0.3.0_x64-setup.exe`（2.60 MiB，NSIS，按用户安装到 `%LOCALAPPDATA%`，开始菜单有快捷方式）
- 系统：Windows 10/11 x64，需要 WebView2 Runtime（缺失时安装器会自动引导安装）
- SHA-256：`b90df5025daf994ebe3194b73358464cf13703a51e60686b3a95cae7ce748bfe`

> **安装前请先完全退出正在运行的墨读**（旧版 `modu.exe` 被占用时会报「无法打开要写入的文件」）。
> 若提示该错误：退出墨读后点「重试」；仍不行则「中止」重装，或换到可写目录。
> 一直用同一种安装方式（都普通权限或都管理员），不要混用，可避免目录属主带来的权限问题。

### B. 便携版（免安装，适合 U 盘 / 不想装）

- 文件：`墨读_0.3.0_portable_x64.zip`（3.31 MiB，解压即用）
- 内容：`Modu.exe` + `启动（便携模式）.cmd` + `使用说明.txt`
- 想随身携带：双击 `启动（便携模式）.cmd`，数据写到同目录 `ModuData\`，整个文件夹拷走即可
- SHA-256：`1c80355d6c7aeec70d306af75468568d44152cc7ddd9b48576b03a001affaee4`

> **首次运行可能被 Windows SmartScreen 拦截**（提示「已保护你的电脑 / 发布者：未知」）。
> 这是未做代码签名的新下载文件的默认行为，不是病毒告警。
>
> **安装版**：点「更多信息 → 仍要运行」，或右键安装包 → 属性 → 勾选「解除锁定」后再装。
> **便携版**：先右键 ZIP → 属性 → 勾选「解除锁定」→ 再解压，解压出来的 `Modu.exe` 不带网络标记，双击通常不再提示；或用 7-Zip 解压。
>
> 两种包都建议先校验 SHA-256 与上面一致再运行：
> `certutil -hashfile <文件名> SHA256`
>
> 我们正在推进代码签名（SignPath Foundation 开源免费签名），后续版本会逐步消除该提示。

## 升级说明

- 数据库 schema 与 v0.2.0 一致，直接覆盖安装即可，书架、进度、书签、批注全部保留。
- 旧版保存的阅读位置会在首次打开时自动升级为 v2（带文本锚点），升级后位置只会更准。

## 已知限制

- 搜索结果只覆盖当前打开的书，跨书搜索未做。
- 批注依赖「引文 + 前后文」定位，若某章文本被外部工具改动到上下文都对不上，该条批注会跳过不画（数据仍保留）。
- Windows 无边框窗口没有系统圆角与投影，缩放走自绘边缘热区。
- 结构类问题还剩 4 项登记为 backlog（ReaderPage 拆分、主题色板合并等），不影响使用。

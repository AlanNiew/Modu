## 二、Spec 轴

### 缺失 / 不完整
- **P1（F-08/F-09）定位精度不足**：`src/lib/locator.ts` 只存 `{v:1,index,fraction}`；`fraction` 来自当前分页结果，换字号/窗口后页数变化，恢复位置会漂移，达不到验收里的「跨字号/窗口/重启位置不变」。→ Locator v2：加 `quote/prefix/occurrence` 文本锚点，恢复时优先按文本定位。
- **P2（F-18）加密 EPUB 未检测**：全库无 `META-INF/encryption.xml` 判断，DRM 书只会表现为空白/乱码，不是明确中文提示；且 8 个畸形样本只断言了 6 个。
- **P3（F-15）沉浸/全屏不完整**：沉浸模式隐藏了整个 footer（含进度），无「极简进度」；`Esc` 只做 沉浸→书架，不退出全屏；`immersive`/`fullscreen` 状态不记忆。
- **P4（§5.2）章节改写不彻底**：`object data` 被整体丢弃而非改写；`<meta http-equiv="refresh">`、`<form>`、`javascript:` 链接未中和，章节文档可能被导航走。
- **P5（§6.4）快捷键表与现实冲突**：规范 `Ctrl+B`=加书签、`Ctrl+F`=书内搜索；实现是 `Ctrl+B`=侧栏、`Ctrl+K`=搜索、自创 `Ctrl+D`。且 F4/F12/Ctrl+=/-/0/Ctrl+W/↑↓/Home/End 缺失。
- **P6（F-25）批注导出 Markdown 缺失**：任务书标 P1「M3–M4 内完成」，代码与文档均无痕迹。
- **P7（F-19，M4 引入）换章后划线消失**：paginator 先发 `load` 后发 `relocate`，`load` 用上一章 `lastRelocate.index` 绘制；`relocate` 因 `currentDoc !== lastRenderedDoc` 已为 false 不补画。
- **P8（健壮性）zip 条目无大小上限**：`read_entry` 直接 `Vec::with_capacity(file.size())`，恶意 EPUB 可声明超大解压尺寸造成 OOM。
- **P9（搜索质量）块级标签无分隔**：`html_to_text` 对 `</p>`、`<br>` 等不产出分隔符，导致「第一章纸上的灯」式粘连，影响 FTS 短语与摘录。
- **P10（F-14）快捷键缺口**（与 P5 合并处理）。
- **P11（F-16）性能无实测记录**：交付说明声称冷启动 < 1.5s，但仓库没有可复现的测量方法/记录。

### 范围蔓延
- DEV-only `window.__moduAnno` 探针（`ReaderView.tsx`，`import.meta.env.DEV` 门控）——保留但注明用途；不得进入 release。

## 三、加固优化方案（本轮全部实施）

**A. 正确性（P0）**
1. Locator v2：`{v:2,index,fraction,quote,prefix,occurrence}`；读旧 v1 自动降级；`ReaderView` 提供 `getAnchor()` 与 `restore(locator)`；进度/书签保存改为带文本锚点，恢复优先文本定位、失败回退 `fraction`。
2. 划线重画：按「渲染时的章节序号」判断，而不是 DOM 身份；换章必重画。
3. 加密 EPUB：解析 `META-INF/encryption.xml`（存在性判断）→ `AppError::Unsupported("这本书带有 DRM 加密，暂不支持打开")`。
4. zip 条目上限：单条目 64 MiB、单本累计 512 MiB；超限报明确错误。
5. `html_to_text`：块级结束标签产出空格。
6. `sectionLoader`：中和 `meta[http-equiv=refresh]`、`form`、`javascript:`；`object` 保持丢弃并在注释说明与 CSP `object-src 'none'` 一致；CSS `url()` 正则支持嵌套括号。
7. 快捷键统一：`src/lib/shortcuts.ts` 单一表 → `App`/`ReaderPage`/`HelpDialog` 共用；`Ctrl+B` 加书签、`Ctrl+F` 搜索、`F4` 侧栏、`F12` 沉浸、`Ctrl+W` 返回书架、`↑/↓` 上/下一章、`Home/End` 章首章尾、`Ctrl+=/-/0` 字号、`Ctrl+,` 排版面板。
8. Esc 阶梯：关闭浮层 → 退出沉浸 → 退出全屏 → 返回书架；沉浸模式保留底部细进度条。
9. F-25 批注导出 Markdown：Rust 命令 `annotation_export_markdown(library_id) -> String`，前端 `save()` 选路径后写文件（新增 `write_text_file` 命令，不走 fs 插件）。

**B. 结构（P1）**
10. `src/renderer/quote.ts`：`DocIndex`/`buildDocIndex`/`rangeFromFlat`/`locateQuote`/`waitForChapterDoc`；删除重复的 `findQuoteRange`。
11. `src/lib/annotationColors.ts`：颜色 → {label, swatch} 单一来源；Rust 侧 `AnnotationColor` 改为 serde 枚举（非法值报错而不是静默改黄）。
12. `src/lib/format.ts` + `src/components/NoteEditor.tsx`：书签与批注面板共用。
13. `helpOpen` 由 `App` 传入 `ReaderPage`，删除 DOM 嗅探。
14. `AppError::Validation` 用于「批注内容不能为空」等用户输入错误。

**C. 测试与文档（P1）**
15. Rust 测试：加密样本、zip 上限、Markdown 导出、块级分隔；fixture 自建，不依赖 `.books/`。
16. 前端测试：Locator v2 往返与降级、`sectionLoader` 改写矩阵（src/srcset/svg/link/style/@import/refresh/form/javascript:）、快捷键表与 HelpDialog 一致性。
17. 文档：本文件、任务书附录 C v1.7 / D 更新、交付说明新增「十五、M0–M2 审查与加固」、用户手册快捷键表同步。
18. 验证：`pnpm typecheck`、`pnpm test`、`cargo test --lib`、`pnpm tauri build --bundles nsis`；更新版本 0.2.1；提交推送。

**D. 暂缓（记录原因）**
- `ReaderView` 批注覆盖层/工具条拆 `annotationLayer.ts`：纯重构、无行为收益，等下一轮做阅读器功能时随动拆。
- 冷启动自动基准：需要 profile 构建与多次采样，和发布流水线一起做。
- 颜色枚举的 DB 值迁移：当前数据只有四种合法值，改 serde 枚举时读侧做兜底即可，无需迁移。

## 实施结果（v0.3.0）

本次按方案 A（正确性）、B（结构）、C（测试与文档）三档执行，逐项状态如下。

### A 正确性（全部完成）

| # | 问题 | 修复 |
|---|------|------|
| A1 | 进度/书签只存「章号 + 页分数」，换字号后位置漂移 | Locator 升到 **v2**：`{v:2, index, fraction, quote?, prefix?, suffix?}`，恢复时先按章/分数跳转，再用「引文 + 前后各 32 字」定位到原句；旧数据自动升级 |
| A2 | 解压无上限，zip 炸弹可 OOM | 单条目上限 **64 MB**，超限返回明确错误 |
| A3 | 加密书（`META-INF/encryption.xml`）不识别，报「条目不存在」 | 解析 encryption.xml：正文加密 → 明确提示「带 DRM 加密，无法解密」；仅字体加密放行 |
| A4 | 非 EPUB 文件提示晦涩 | 缺 `META-INF/container.xml` 时给出中文原因（含「是不是把 zip 改了后缀」） |
| A5 | 书名缺失写死「未命名」，文件名回退分支是死代码 | 回退文件名主干 |
| A6 | 关键词搜索里 `%`/`_` 未转义（LIKE 通配符生效） | LIKE 加 `ESCAPE '\'`，并用标题 `100%_真实` 的测试固定行为 |
| A7 | `html_to_text` 不识别块级标签，`<p>甲</p><p>乙</p>` 拼成「甲乙」 | 块级标签（p/div/br/li/td/h1–h6…）产出分隔空格 |
| A8 | 书内 CSS 可破坏分页/暗色主题；无「净版」 | 新增净版开关（`respectPublisherStyles=false`）：重置字号/颜色/浮动/absolute/宽度，只按应用排版渲染 |
| A9 | 换章后目录把整章所有小节都点亮 | 目录高亮带 fragment 精确匹配，缺失时退回本章首项 |

### B 结构（完成 4 项，其余登记为后续）

- 完成：批注颜色从裸字符串改为 serde 枚举 `AnnotationColor`；`command` 层删掉 3 个死命令并新增导出/写文件；`protocol` 的 CORS/缓存与错误响应合并；`ReaderView` 的 `getContents()[0].doc` 抽成 `currentDoc()`，并抽出文本锚点捕获/恢复。
- 后续（记入 backlog）：ReaderPage（约 900 行）拆分为搜索面板 / 进度条 / 导出等子组件；`READING_THEMES` 与 `CHROME_PALETTES` 合并为单一调色板来源；`useAsyncResource` 统一三处「加载中 + 错误 + 刷新」；`to_info` 收敛 `OpenedBookInfo` 构造。

### C 测试与文档（完成）

- Rust 测试 **17 项**（新增：块级文本分隔、LIKE 转义、批注 Markdown 导出、加密书拒绝、畸形样本、大书基准）。
- 前端测试 **23 项**（新增：Locator v2 升级/锚点/异常、`sectionLoader` 的清洗与资源改写）。
- `cargo clippy --lib --tests -- -D warnings` 零告警；新增 `eslint.config.js`（`pnpm lint`）零告警。
- 实测（200 章 / 26 万字基准书）：open 16 ms、全文读取 25 ms、导入+索引 72 ms、搜索 <1 ms。
- 真书回归：打开《肖申克的救赎》→ 翻页 → 改字号（3 页变 6 页，进度保持 16%）→ 退出重开仍回到同一句（17%），日志无报错。

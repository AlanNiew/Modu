## 1. 安装与启动

**系统要求**

- Windows 10 / 11（64 位）
- WebView2 Runtime（Win11 自带；Win10 若缺失，安装包会尝试自动下载，需要联网）

**安装**

1. 双击 `墨读_0.2.0_x64-setup.exe`。
2. 默认按当前用户安装（无需管理员权限），装完在开始菜单出现「墨读」；安装目录在 `%LOCALAPPDATA%\墨读`。
3. 首次启动会创建数据目录（见 [第 11 节](#11-数据备份与迁移)）。

**便携模式（可选）**

如果想把书库和设置放到自己的目录（比如 U 盘），启动前设置环境变量：

```powershell
$env:MODU_DATA_DIR="D:\ModuData"
& "<安装目录>\modu.exe"
```

之后 `modu.db` 与 `covers/` 都会落在 `D:\ModuData`。不设置时用系统的标准应用数据目录。

## 2. 界面速览

墨读使用无边框窗口，标题栏和应用是一体的：

```
┌──────────────────────────────────────────────────────────────┐
│ [logo] ‹ 书架  书名 / 当前章节     [图标按钮组] │ ─ □ ✕      │
├───────────────────────────┬──────────────────────────────────┤
│ 侧栏：封面 / 目录 / 书签 / │ 正文区（单栏居中，可翻页或滚动） │
│ 批注 / 搜索                │                                  │
├───────────────────────────┴──────────────────────────────────┤
│ 第 7 / 40 章   3 / 6 页 · 16%   [进度条]        OEBPS/…      │
└──────────────────────────────────────────────────────────────┘
```

- **拖动窗口**：按住标题栏空白处拖动；双击标题栏最大化/还原。
- **缩放窗口**：拖动窗口四边或四角。
- **窗口按钮**：右上角最小化 / 最大化 / 关闭。
- **标题栏按钮**：书架页是「搜索书架」「导入 EPUB」「快捷键与帮助」；阅读页是「添加书签」「阅读排版设置」「侧栏」「沉浸模式」「全屏」「帮助」，顺序固定。
- 书架页按 `F1` 随时可以看快捷键清单。

## 3. 书架

### 3.1 导入书

三种方式，效果一样：

1. **拖拽**：把 `.epub` 文件（可以多选）直接拖到窗口里，松手即导入。
2. **导入按钮**：点标题栏的「导入 EPUB」，在文件对话框里多选。
3. **重复导入**：同一本书再导入一次不会产生重复条目（按文件指纹 + 路径识别），会更新元数据。

导入时会解析书名、作者、语言、出版社、简介、封面、章节结构、目录，并统计每章字数。几 MB 的书通常零点几秒；20 万字的长篇一两秒。

### 3.2 书架卡片

每本书显示：

- **封面**（原书封面，缺失时用书名首字生成渐变卡）
- **书名 / 作者**
- **章节数 · 总字数 · 阅读进度**

### 3.3 搜索、筛选、排序

- **搜索**：标题栏「搜索书架」或直接在顶部搜索框输入，按书名/作者/出版社匹配（输入即搜，带防抖）。
- **筛选**：全部 / 在读 / 未读 / 读完。
  - 在读：进度 > 0.1% 且 < 99.9%
  - 未读：进度 ≤ 0.1%
  - 读完：进度 ≥ 99.9%
- **排序**：最近阅读 / 书名 / 作者 / 入库时间。

### 3.4 移出书架

卡片右上角「更多」→「移出书架」。只删除书库记录、封面和阅读数据，**不会删除你磁盘上的 epub 文件**（会二次确认）。

## 4. 开始阅读

- 点卡片（或卡片上的「继续阅读 / 开始阅读」）进入阅读页。
- 打开时自动恢复到上次位置：精确到「第几章 + 章内第几页」。换字号、换字体后位置也不会丢。
- 阅读进度在翻页后自动保存（约 0.7 秒防抖），返回书架时再同步一次。
- 返回书架：点左上角「‹ 书架」、按 `Esc`，或按几次 `Esc`（沉浸 → 书架）。

**脚注**：正文里的脚注链接会跳到对应注释页/段落，注释页里的回链能跳回原位。

**外链**：书里的 `http(s)` 链接不会在应用内打开，而是交给系统默认浏览器。

## 5. 翻页、滚动与导航

墨读有两种阅读方式，在「阅读排版设置 → 阅读方式」里切换，切换时**不重开书、位置保持**。

### 5.1 翻页模式（默认）

- **键盘**：`→` / `PageDown` / `空格` 下一页；`←` / `PageUp` 上一页。
- **鼠标滚轮**：向下滚翻下一页，向上滚翻上一页（累积 50px 触发；有 320ms 冷却，防止触控板一滑翻好几页）。`Ctrl + 滚轮` 保留给系统缩放，不翻页。
- **触控板**：横向或纵向滑动都可以翻页。
- **点按**：点正文**左侧 30%** 上一页，点**右侧 30%** 下一页；点中间区域不翻页（避免误触）。
- 页脚显示：「第 N / M 章 · 第 p / q 页 · 百分比」。

### 5.2 滚动模式

- 正文连续上下滚动，滚轮/触控板就是普通滚动，右侧出现滚动条。
- 适合想「一直往下读」的书；`→` / `←` 仍然可以按「屏」跳。

### 5.3 目录

左侧「目录」页签是完整的目录树：

- 支持多层目录（部 / 卷 / 章），带折叠箭头。
- 当前所在章节自动高亮。
- 点击即跳转；目录项指向的锚点会精确跳到段内位置。

### 5.4 侧栏

- 点标题栏「侧栏」按钮，或 `Ctrl+B` 显示/隐藏。
- 侧栏固定宽度，阅读区保持居中，不会因为开关侧栏而丢失位置。

### 5.5 沉浸模式与全屏

- **沉浸模式**：隐藏标题栏、侧栏和页脚，只留正文；右上角有半透明退出按钮；按 `Esc` 退出沉浸（再按一次回书架）。
- **全屏**：`F11` 或标题栏「全屏」按钮，在无边框窗口里切到全屏；再按一次还原。

## 6. 排版设置

点阅读页标题栏的「阅读排版设置」打开面板，所有改动**实时生效并自动保存**（下次打开还是这套设置）。

| 设置项 | 范围 / 选项 | 说明 |
|---|---|---|
| 主题 | 跟随系统 / 浅色 / 羊皮纸 / 护眼绿 / 雾蓝 / 藕粉 / 深色 / 深夜黑（8 套） | 同时作用于宿主界面和正文；浅色系四套在上排，雾蓝/藕粉/深色/深夜黑在下排 |
| 字体 | 宋体 / 黑体 / 楷体 | 优先用系统里的思源宋体/Noto Serif CJK，缺字体时回退 |
| 字号 | 13 – 34 | 步进 1 |
| 行高 | 1.3 – 2.4 | 步进 0.05 |
| 版心宽度 | 520 – 1000 | 正文最大行宽（px），越大多越宽 |
| 首行缩进 | 开 / 关 | 默认按中文习惯缩进 2 字符 |
| 阅读方式 | 翻页 / 滚动 | 见第 5 节 |

面板底部「恢复默认排版」可一键还原以上设置（不影响书库、进度、书签、批注）。

**关于主题**：选「跟随系统」时，墨读会跟着 Windows 的深/浅色自动切；在深色系统下用「羊皮纸 + 宋体」是作者推荐的长时间阅读组合。

## 7. 书签

- **加书签**：`Ctrl+D`，或点标题栏「添加书签」。
- 书签记录的是「章节 + 章内位置 + 当前页第一段摘录」，换字号后仍能回到原处。
- 打开左侧「书签」页签：点一条即可跳转。
- **备注**：鼠标悬停书签 →「备注 / 改备注」→ 输入后 `Ctrl+Enter` 保存、`Esc` 取消（也可以点按钮）。
- **删除**：悬停 → 删除图标，立即删除，无撤销。

## 8. 划线批注

### 8.1 划线

1. 在正文里**选中一段文字**。
2. 选区上方浮出工具条：四个颜色圆点（黄 / 绿 / 蓝 / 粉）+「写批注」。
3. 点颜色 → 高亮落库，侧栏「批注」自动切换到该条。

> 选中后如果工具条没出现，重新拖选一次即可；点击正文空白处工具条会收起。

### 8.2 备注

- 划线后可以在「批注」页签里点「写批注」，或者选中文字时直接点工具条上的「写批注」。
- 备注支持多行，`Ctrl+Enter` 保存、`Esc` 取消。
- 保存后输入框自动收起，备注以黄色块形式显示在批注卡片里。

### 8.3 管理

在「批注」页签：

- 点引文区域：跳到正文里的该句并重新高亮。
- 「改批注」：修改备注；「删除」：删除整条划线（含备注）。
- 每条显示颜色、所属章节、划线时间。

### 8.4 定位原理（以及为什么重开书还在）

墨读不存固定的字符偏移，也不存 CFI，而是记住：

**引文全文 + 前后各 32 个字的上下文 + 这句话在本章第几次出现**

重新打开书时，用这三样在章节正文里重新找位置。所以换字号、换字体、换主题、窗口大小变化都不影响划线；只有当你用别的工具修改了这本书的章节文本，导致上下文对不上时，那条划线才会暂时不显示（数据仍保留，改回来会恢复）。

### 8.5 在正文里点划线

点正文里已划线的文字，会直接切到「批注」页签并选中对应条目，方便查看/修改备注。

## 9. 全书搜索

- 打开方式：`Ctrl+K`，或点侧栏「搜索」页签。
- 输入即搜（约 280ms 防抖），输入 1 个字也能搜。
- 结果列表显示：所属章节名、两行上下文摘录（命中词加粗高亮）。
- 点结果 → 跳到目标章节的**精确位置**（不是章首），命中句会在正文里高亮几秒。
- 首次搜索某本书时会自动建全文索引（几秒内完成，之后秒回；老书无需重新导入）。

**搜索范围**：当前打开的书。跨书（书架级）搜索暂未提供。

## 11. 数据、备份与迁移

### 11.1 数据放在哪

默认（Windows）：

```
%APPDATA%\Modu\
├─ modu.db        # 书库、进度、书签、批注、全文索引（SQLite，含 -wal/-shm）
└─ covers\        # 从 epub 提取的封面图片
```

从 ≤ 0.3.1 升级上来时，首次启动会**自动把** `%APPDATA%\com.alanview.epubreader` 整个目录改名迁移到 `%APPDATA%\Modu`（同盘改名，瞬间完成）；若因目录被占用等原因迁移失败，程序会继续使用旧目录，不会丢数据。

> 为什么换目录：安装包的卸载程序里有个「删除应用数据」勾选项，它删的是 `%APPDATA%\<应用标识>`。数据改放独立目录 `Modu` 之后，**卸载墨读不会再碰到书库**——即使误勾该项，书架、进度、书签、批注也都还在。

排版设置存在 WebView 的 localStorage 里（`modu:reader-settings`），也在同一 WebView 数据目录下。

便携模式：设置 `MODU_DATA_DIR` 指向任意目录（见第 1 节）。

### 11.2 备份

1. 关闭墨读。
2. 整个复制上面的数据目录（`modu.db` + `covers/`，以及 WebView 数据目录里的设置）。
3. 恢复时把备份目录放回原位，或把 `MODU_DATA_DIR` 指向备份目录。

> 不要只拷 `modu.db` 而漏掉 `-wal` 文件：如果上次未正常退出，最近的进度可能还在 WAL 里。

### 11.3 重置

- **重置排版**：排版面板 →「恢复默认排版」。
- **清空书库**：关闭墨读后删除 `modu.db` 与 `covers/`（epub 原文件不受影响）。

## 12. 自动更新

安装版（`墨读_x.y.z_x64-setup.exe`）自带应用内更新；便携版（ZIP）不参与自动更新，升级时手动替换 `Modu.exe` 即可。

### 12.1 检查与安装

- **启动时静默检查**：默认开启。发现新版本会弹出更新面板，显示版本号、更新说明与下载进度。
- **手动检查**：书架标题栏的「检查更新」按钮（圆形箭头图标）。
- 点「立即更新」后：下载更新包 → 用内置公钥校验签名 → 静默安装 → 提示重启。全程不弹安装向导。

### 12.2 关闭自动检查

更新面板左下角有「启动时自动检查更新」勾选框，取消勾选后，只有手动点「检查更新」才会联网。该选择会保存在本机。

### 12.3 失败怎么办

| 现象 | 处理 |
| --- | --- |
| 提示网络错误 | 稍后点「重新检查」；公司网络/代理可能拦截 GitHub |
| 提示校验失败 | 更新包被篡改或损坏，已自动中止，不会安装；可到发布页手动下载 |
| 安装时弹出 UAC | 应用装在受保护目录（如 `C:\Program Files`、`D:\Windows Tools`）时会这样；用普通权限装到自己可写的目录（如 `D:\Apps\墨读`）可避免 |
| 更新后想回到旧版 | 到 Releases 下载上一版安装包覆盖安装即可，书库与批注数据保存在数据目录，不受影响 |

> 更新只会替换程序文件，书架、进度、书签、批注都在数据目录里（见第 11 节），升级不会丢失。

## 13. 常见问题

**Q：安装到一半报「无法打开要写入的文件 …\modu.exe」？**
按可能性从高到低处理：
1. **换安装目录（最常见的解决办法）**：向导第二页「安装位置」里，把默认的 `C:\Users\<你>\AppData\Local\墨读` 改成 **D 盘上你自己可写的目录**，例如 `D:\Apps\墨读`（不存在没关系，向导会创建）。装有联想电脑管家 / 火绒等安全软件的机器上，其「安装行为防护」可能拦截安装器往 AppData 写可执行文件；换到非 AppData 目录通常直接通过，普通权限即可。
2. **彻底退出旧版墨读**（含任务管理器里残留的 `modu.exe`）后点「重试」——`modu.exe` 被占用也会报同一句话。
3. **旧版是用管理员权限装的**：安装目录属主可能是 Administrators，普通权限写不进去；要么继续用管理员装，要么先在「应用和功能」卸载旧版，再按第 1 条换目录装。
4. 仍失败：在安全软件里把安装包与安装目录加白，或先用便携版（ZIP）。
> 小建议：一直用同一种方式安装（要么都普通、要么都管理员），混用最容易踩到属主/权限问题。
> 数据安全：0.3.2 起数据目录是 `%APPDATA%\Modu`，**卸载程序不会删除它**；0.3.1 及更早版本的数据在 `%APPDATA%\com.alanview.epubreader`，卸载时若勾「删除应用数据」会被删掉——升级到 0.3.2 后程序会自动迁移，不必手动搬。

**Q：安装时弹出「Windows 已保护你的电脑」（SmartScreen），说「发布者：未知」？**
这是 Windows 对**未做代码签名**的新下载文件的默认拦截，不是病毒告警。原因：文件从网络下载后带 Mark-of-the-Web，且证书缺失 → Defender SmartScreen 没有「信誉记录」可用。
处理方式（任选一种）：
1. 点窗口里的 **「仍要运行」**；若只有「不运行」，先点 **「更多信息」→「仍要运行」**。
2. 更彻底：右键**安装包** → 属性 → 勾选 **「解除锁定」** → 确定，再双击安装（只是去掉「来自网络」的标记）。
3. 用便携版（ZIP）：**先**右键 ZIP → 属性 → 勾选「解除锁定」→ **再**解压，解压出的 exe 不带网络标记，双击通常不再提示；用 7-Zip 解压也有同样效果。
建议顺手校验文件完整性：`certutil -hashfile <文件名> SHA256`，与发布页给出的 SHA-256 对照一致再运行。
说明：当前版本尚未购买代码签名证书，因此发行者显示「未知」。这不影响程序功能与安全性；后续计划通过开源免费签名（SignPath Foundation）或商业证书消除该提示。

**Q：安装版和便携版有什么区别？**
安装版（`墨读_x.y.z_x64-setup.exe`）默认装到 `%LOCALAPPDATA%\墨读`（可改成任意可写目录，如 `D:\Apps\墨读`），开始菜单有入口、支持自动更新，卸载走「应用和功能」；便携版（`墨读_x.y.z_portable_x64.zip`）解压即用，双击 `启动（便携模式）.cmd` 会把数据放在同目录 `ModuData\`，适合放 U 盘或不想安装的场景，但不参与自动更新。两者功能一致、数据格式相同，可以直接互换数据目录。

**Q：双击安装包后提示需要 WebView2 / 安装很慢？**
安装包内置的是「在线引导」（约 2 MB）。首次安装需要联网下载 WebView2；离线环境请先手动安装 Microsoft Edge WebView2 Runtime。

**Q：打开书报「不是有效的 EPUB」/「缺少 container.xml」？**
文件损坏、扩展名被改成 .epub 的其它格式、或打包时缺 `META-INF/container.xml`。可以先用别的阅读器验证文件本身。

**Q：中文乱码？**
墨读会自动识别 UTF-8 / UTF-16 / GBK / GB18030（含未声明编码的老书）。仍乱码的书通常用了更少见的编码（如 Big5），暂不支持切换编码。

**Q：图片显示不出来？**
先确认原书在其它阅读器里正常。墨读支持常见图片格式（JPEG/PNG/GIF/WebP/SVG/BMP/TIFF）；引用路径大小写不一致的 zip 会自动回退匹配，但极少数书用绝对路径引用图片会失败。

**Q：字体不是宋体/黑体？**
排版面板选的是「字体族」，实际字形取决于系统里装的字体。建议安装「思源宋体 / 思源黑体」（Source Han Serif/Sans SC）或 Noto Serif/Sans CJK，效果最好。

**Q：窗口拖不动？**
只有标题栏空白处可拖动；图标按钮和窗口按钮不参与拖动。双击标题栏可最大化。

**Q：搜索没结果？**
确认在阅读页（搜索只搜当前书）、输入至少 1 个字。刚导入的大书第一次搜索需要几秒建索引，再搜一次就有结果。

**Q：划线重开书后没显示？**
见 [8.4 定位原理](#84-定位原理以及为什么重开书还在)：通常是这本书的章节文本被外部工具改动过。

**Q：大书打开/翻页卡？**
墨读按章懒加载，单章不会因为全书大而变慢；导入时一次性统计字数。200 章 / 26 万字的基准书在开发机上 open 约 16ms、全文读取约 25ms、导入+索引约 72ms。

**Q：为什么没有「云同步 / 跨设备进度」？**
当前版本是纯本地应用，数据都在本机；可以用第 11 节的备份方式手动迁移。

## 14. 已知限制

- **仅支持 EPUB**（EPUB 2 / 3）。PDF、MOBI、AZW3 暂不支持。
- **搜索只覆盖当前书**，没有书架级全局搜索。
- 脚注是「跳转」而非「浮层预览」。
- 固定版式（fixed-layout，漫画/画册类）EPUB 未做专门适配，可能排版异常。
- 划线支持四色，但一条划线只有一个颜色；不支持在划线里再插入图片/公式。
- 批注依赖「引文 + 上下文」定位，章节文本被外部改写后可能暂不显示（数据保留）。
- Windows 无边框窗口没有系统级圆角与投影，缩放由自绘边缘热区完成。
- 无自动更新（需要新版安装包手动覆盖安装，数据会保留）。

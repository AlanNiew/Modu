## 二、本阶段交付内容

### M0 技术验证（门禁）

| 验证点 | 结果 |
| --- | --- |
| 脚手架可 `pnpm tauri dev` | ✅ |
| Rust EPUB 容器解析（zip → container.xml → OPF → spine / nav / ncx / 封面 / 元数据） | ✅ `cargo test` 覆盖 |
| 资源链路：章节 HTML 走同源 `blob:` iframe，图片 / CSS / 字体走 `http://epub.localhost` 协议 | ✅ 0 CSP violation、0 404 |
| 渲染内核选型 | ✅ vendor foliate-js `78914aef4466eb960965702401634c2cb348e9b1`（见下「选型说明」） |
| NSIS 打包 → 安装 → 启动 | ✅ 安装包 2.56 MiB（上限 20 MB） |

**选型说明（替代单独的 spike-report）**：foliate-js 的 paginator 用 CSS multi-column + `scrollWidth` 反算列数，支持 Range 级定位、列数 > 2、分页/滚动切换不重载；epub.js 的 npm 包落后仓库 4 年且无搜索模块。因此采用 foliate-js 作分页内核，容器解析与资源服务全部放在 Rust，前端只做纯 TS 适配层（`src/renderer/foliateBook.ts`）。已为内核打了两处最小补丁，均带 `// modu patch:` 注释，升级 vendor 时需重新应用。

### M1 数据层与书库

- **SQLite schema v1**（`src-tauri/src/db.rs`）：`books` / `chapters` / `progress` / `bookmarks` / `chapters_fts`（FTS5 trigram），WAL + `user_version` 迁移，迁移幂等。
- **导入流水线**（`src-tauri/src/library.rs`）：blake3 文件指纹去重 → 解析 OPF → 抽封面落盘 → 逐章统计字数（自写 HTML 文本扫描器，处理注释/script/style/实体/未闭合标签）→ 单事务 upsert。
- **书库命令**：导入、列表（排序 recent/title/author/added × 筛选 all/reading/unread/finished × 关键词搜索）、删除、打开、详情。
- **书架 UI**：虚拟滚动网格（`@tanstack/react-virtual`，按容器宽度反算列数）、封面/占位、进度条、搜索防抖、筛选 tabs、排序下拉、导入进度、错误横幅、空态、**拖拽窗口导入**（`onDragDropEvent`，多文件、仅 .epub）、移出书架确认。

### M2 阅读器核心

- **排版**：单栏分页（`max-column-count=1` + `max-inline-size` 版心），4 套主题（深/浅/羊皮纸/护眼绿）、字体三选一（宋/黑/楷）、字号 13–34、行高 1.3–2.4、版心 520–1000、页边距 16–120、首行缩进、两端对齐，全部**实时生效**并持久化。
- **导航**：目录树（保留嵌套、可折叠、当前章高亮）、左右两侧点按翻页、**鼠标滚轮翻页**（累积 50px 触发、320ms 冷却防连翻；触控板横向滑动也可翻；Ctrl/⌘+滚轮保留给缩放）、键盘 ←/→/PageUp/PageDown/Space、跨章链路（`ch02.xhtml#n3` 切章 + 片段定位）。
- **进度**：Locator `{"v":1,"index":N,"fraction":F}`（章节序号 + 章内比例），防抖 700ms 落库，重开自动恢复；不依赖像素，改字号/窗口后仍落在同一段。
- **书签**：添加（带章节名 + 当前可见文本摘录）、列表、跳转、删除，落库持久化。
- **沉浸模式**：隐藏顶栏/侧栏/底栏，Esc 逐级退出（先退沉浸再返书架）。
- **其它**：书籍打开/关闭句柄管理、外链交系统浏览器（`tauri-plugin-opener`）、阅读页左上「书架」返回。

## 五、已知限制（诚实清单）

1. **交互类 UI 未自动化点验**：排版面板、沉浸按钮、书签面板的点击链路由单测与数据层自检覆盖，但没有真正的鼠标自动化（本机 WebView2 上 Playwright/CDP 派发点击持续失败）。这几项请你手工点一遍。
2. **段内大图会被 justify 拉宽**：书内 CSS 为 `text-align: justify` 且图片在段落内时的固有表现，非渲染 bug。
3. **未做搜索 / 滚动模式 / 批注高亮**：属 M3–M4 范围。
4. **性能未压测**：目前最大样本 160 万字 / 193 章可正常打开，未做 50MB 级书籍的打开耗时基准。
5. **仅 Windows**：`build.target` 固定 `chrome105`，未适配 macOS/Linux 打包。
6. **升级内核需重打补丁**：`src/renderer/vendor/foliate/` 内两处 `// modu patch:` 补丁在升级 vendor 时需重做。

## 九、M2.6 反馈修复（2026-11-04 二次反馈）

1. **书架排版遮挡 / 封面不自适应**：行高过去写死 316px，而卡片宽度是 `1fr` 拉伸的——窗口一宽，2:3 封面撑高后就把下一行盖住，书名/作者/字数像被吃掉。现在由容器实测宽度推导列数 → 卡片宽度 → 行高（`rowHeight = round(cardWidth × 1.5) + 文字区 + 行距`），并用 `ResizeObserver` 跟随窗口缩放、变化时让虚拟列表 `measure()` 重算；卡片填满整格、封面 `aspect-[2/3]` + `object-cover` 等比裁切。已用 CDP 实测 11 张卡片：封面统一 187×280、文字区在封面下方 8px、行高 365（含 23px 行距），无重叠。
2. **排版设置按钮点不开**：`TitleBarButton` 原来只接收固定 props，而 Radix 的 `Popover.Trigger asChild` 会把 `onPointerDown`/`aria-expanded`/`ref` clone 到按钮上——不透传就丢事件，真实鼠标点击自然没反应（此前用合成 `element.click()` 验证能开，正好掩盖了这个问题）。现改为 `forwardRef` + `...rest` 透传 props。已用 CDP `Input.dispatchMouseEvent` 派发真实 pointerdown/up 复验：`aria-expanded="true"`、`role="dialog"` 面板 304×457 正常弹出，五套主题 + 字体/字号/行高/版心/缩进全部可用。

**验证记录**：`pnpm typecheck` 0 错误；`pnpm tauri build --bundles nsis` 重出安装包；书架截图（`_shelf_fix.png`）与阅读器弹层截图（`_reader_panel.png`）均已核对。

## 十、应用标识（Logo）

- **构思**：一滴墨落进摊开的书里。墨滴＝「墨」（内容），摊开的书页＝「读」（载体）；两者之间留一点空气，墨滴尖端正对书脊的 V 形开口，读起来是「墨将落未落」的一瞬。配色沿用应用自身色板：墨砖底（`#2a2a3c → #0e0e16`）、羊皮纸书页（`#fdf8ea → #e6d9bb`）、墨滴由淡紫过渡到蓝（`#dccbff → #7aa2f7`），所以在深色/羊皮纸主题下都不突兀。
- **交付物**：矢量源 `src/assets/logo.svg`（1024×1024，纯几何路径，无位图、无字体依赖）；`pnpm tauri icon src/assets/logo.svg` 生成 `src-tauri/icons/` 全套（`icon.ico`、`icon.png`、`32x32/64x64/128x128/128x128@2x`、Windows Store 磁贴、macOS `.icns`、Android/iOS 占位）。
- **应用内使用**：标题栏左上角品牌位改用图标本身（`TitleBar.tsx`），浏览器标签页用 `public/icon.svg` 作 favicon；NSIS 安装包、开始菜单与任务栏图标均来自 `src-tauri/icons/icon.ico`。
- **小尺寸校验**：16/32/64px 下「墨滴 + 书」仍是两个可辨的形，未用细线或渐变细节承载语义。
